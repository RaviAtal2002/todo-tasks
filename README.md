# 📝 Simple To-Do App

A simple, easy, and lightweight To-Do list application built with clean HTML, CSS, and JavaScript.

## ✨ Features
- **Add tasks**: Type a task and press Enter or click "Add".
- **Complete tasks**: Click the checkbox or task text to strike through.
- **Delete tasks**: Click the "Delete" button to remove a task.
- **Clear All**: Remove all tasks at once.
- **Task Counter**: Live count of remaining active tasks.
- **LocalStorage**: Your tasks are saved automatically in your browser.
